anti-mage — browser environment assessment

Measurements taken in this browser, by the script served with this page, and read by the local server that served it.

The groups below show what this browser reported, one row per measurement. They carry no verdicts of their own: the single assessment at the top of the page is computed from all of them together and is the only reading here. It reaches at most instrumented, which says an environment appears modified — of the environment, not of the person using it.

There is no per-group verdict on this page by design. Every value in the rows was computed by this browser, so showing it back reveals nothing to it; saying which group of readings moved the score would tell it which one to change.

A probe marked unsupported found that the facility it needs is not present in this browser. That is recorded as a gap in what could be measured, and never counts against the browser.
